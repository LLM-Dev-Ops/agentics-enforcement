# DDD-004: Cost Domain Model

**Bounded Context:** Core Dispatch (Governance-Core) → Foundational (LLM-CostOps)
**Related ADRs:** ADR-006, ADR-007

---

## Domain Overview

The Cost domain enforces a strict opacity principle: cost values are computed exclusively within LLM-CostOps and exposed to the rest of the fleet only as opaque `CostReference` handles. No other repository may perform cost arithmetic, define cost types, or dereference cost handles. This domain model describes the internal structure of LLM-CostOps and its external interface.

---

## Aggregates

### 1. CostComputation (Aggregate Root)

Represents a single cost computation — the full lifecycle from input parameters to stored result.

```
CostComputation [Aggregate Root]
├── ref_id: CostRefId                  [Identity — globally unique, generated by CostOps]
├── parameters: CostParameters         [Input to the computation]
├── raw_result: RawCostValue           [INTERNAL ONLY — never leaves CostOps]
├── status: ComputationStatus          [pending | computed | expired]
├── computed_at: Timestamp
├── expires_at: Timestamp?             [optional TTL for cached computations]
├── execution_id: ExecutionId          [correlation to the parent execution]
└── requested_by: CoreName             [which Core requested this computation]
```

**Invariants:**
- `raw_result` is NEVER serialized into any external response. It stays within CostOps.
- `ref_id` is the ONLY cost identifier that leaves CostOps.
- `parameters` are immutable after creation.
- Only Governance-Core may request cost computations (enforced by Core assignment model, ADR-006).

## Value Objects

### CostReference (External — defined in Contract Context)
```
CostReference [Value Object — defined in agentics-contracts]
├── ref_id: string              [Opaque handle — no embedded cost data]
└── computed_at: Timestamp      [When the computation occurred]
```

- This is the ONLY cost type visible outside CostOps.
- Consumers treat it as a black box. They can pass it, store it, and return it, but cannot inspect its value.

### RawCostValue (Internal — NEVER exported)
```
RawCostValue [Value Object — CostOps internal only]
├── amount: Decimal             [The computed cost value]
├── currency: CurrencyCode      [e.g., "USD", "TOKEN"]
├── breakdown: List<CostLineItem>
└── model_version: string       [Which cost model version produced this]

CostLineItem [Value Object — CostOps internal only]
├── category: string            [e.g., "compute", "storage", "api_call"]
├── amount: Decimal
└── unit: string                [e.g., "per_request", "per_token"]
```

- `RawCostValue` is NEVER part of any external API, schema, or response.
- It exists only within CostOps's aggregate boundary.

### CostParameters
```
CostParameters [Value Object]
├── resource_type: string       [What resource is being costed]
├── quantity: number            [How much of the resource]
├── tier: string                [Pricing tier]
├── context: Map<string, any>   [Additional pricing context]
└── execution_id: ExecutionId   [For correlation]
```

### CostDetail (Internal resolution result)
```
CostDetail [Value Object — returned ONLY by resolveCostReference, ONLY within CostOps or to authorized display layers]
├── ref_id: CostRefId
├── amount: Decimal
├── currency: CurrencyCode
├── breakdown: List<CostLineItem>
├── computed_at: Timestamp
└── model_version: string
```

- `CostDetail` is the resolved form of a `CostReference`.
- It is returned ONLY by `resolveCostReference()` and ONLY to authorized consumers (e.g., billing display, governance dashboard).

## Domain Events

| Event | Triggered By | Payload | Consumers |
|---|---|---|---|
| `CostComputationRequested` | Governance-Core delegates | parameters, execution_id | CostOps computation engine |
| `CostComputationCompleted` | Computation finishes | ref_id, execution_id (NO raw values) | Governance-Core, audit log |
| `CostReferenceResolved` | Display layer requests detail | ref_id, resolved_by | Audit log |
| `CostComputationExpired` | TTL reached | ref_id | Cache cleanup |

**Critical:** No domain event ever contains `RawCostValue` or `CostDetail` in its payload. Only `ref_id` references are included.

## Domain Services

### CostComputationService
**The primary computation service within LLM-CostOps.**

```
CostComputationService [Domain Service]
├── calculateCost(params: CostParameters) → CostReference
│     1. Validate parameters
│     2. Load current cost model
│     3. Compute raw cost value (internal)
│     4. Generate CostRefId
│     5. Store CostComputation aggregate
│     6. Emit CostComputationCompleted event
│     7. Return CostReference (opaque handle only)
│
└── resolveCostReference(ref: CostReference) → CostDetail
      1. Look up CostComputation by ref_id
      2. If not found or expired: throw CostReferenceNotFound
      3. Return CostDetail (full breakdown)
      4. Emit CostReferenceResolved event
```

### CostModelRegistry
**Manages versioned cost models.**

```
CostModelRegistry [Domain Service]
├── getCurrentModel() → CostModel
├── getModelVersion() → string
└── validateModel(model: CostModel) → ValidationResult
```

## Domain Rules

1. **Opacity Rule:** `RawCostValue` MUST NOT appear in any external API, event payload, or cross-boundary response. Only `CostReference` crosses the CostOps boundary.
2. **Sole Computation Rule:** Only `CostComputationService.calculateCost()` may perform cost arithmetic. No other function, service, or repo in the fleet may compute cost.
3. **Sole Resolution Rule:** Only `CostComputationService.resolveCostReference()` may dereference a `CostReference`. No other service may look up cost values.
4. **Governance-Core Gate Rule:** Cost computation requests MUST come through Governance-Core. Direct calls from other Cores or repos are rejected.
5. **CI Enforcement Rule:** A static analysis hook (`cost-calculation-check`) blocks any PR outside LLM-CostOps that contains cost arithmetic, cost type definitions, or cost library imports.
6. **Meta-Simulation Exemption:** Tier-1 meta simulation contexts are exempt from the CI enforcement rule only. Runtime opacity rules still apply.

---

## External Interface (What Other Contexts See)

From outside CostOps, the cost domain exposes exactly two operations:

```
// Via Governance-Core delegation:
calculateCost(params: CostParameters) → CostReference
resolveCostReference(ref: CostReference) → CostDetail

// That's it. No other cost operations exist outside CostOps.
```

Everything else — models, raw values, breakdowns, line items — is internal to CostOps and invisible to the rest of the fleet.
